# v18 Next Quarter Flow

## Requested behavior
Pressing **End Period / Set Up Next Quarter** should:
1. End the current period intentionally.
2. Advance the game to the next quarter.
3. Move the official clock to that quarter's start boundary (12:00 / 24:00 / 36:00).
4. Apply the next-quarter goalie and four field positions immediately.
5. Leave the clock paused.
6. Show the lineup on the visual field so the coaches can position the girls.
7. Start time only when **Start** is pressed.

## Important distinction
- A substitution NEVER changes the game clock.
- The explicit **End Period / Set Up Next Quarter** button DOES move the game clock to the next quarter boundary because that button intentionally ends the period.

## Automatic 12:00 buzzer
At 12:00, the quarter transition preview still appears. Choosing the lineup now prepares the next quarter without automatically starting its clock.
