# Historical QA notes

These are the QA notes that shipped with v15 through v21, kept for context on
why certain behaviours exist. They are history, not current documentation — for
the current state of the app see `../../README.md`, and for what changed most
recently see `../../V22_FIXES.md`.

Note that the Worker was serving the **v19** front end at the time of the v22
review, so the v20 and v21 notes describe changes that had been written but were
never actually live.
